# ЗАГРАНЬ

Студенческое медиа для школьников и студентов из России, которые хотят поступить в зарубежный вуз: база вузов с ценами и сроками, статьи о документах, экзамене и визе, тесты для выбора страны.

## Стек

- Vite 6
- PostCSS: postcss-nested, postcss-preset-env 11, autoprefixer 10
- HTML, CSS, JavaScript без фреймворков
- Шрифты Rubik Black и Golos Text, подключены локально
- Formspree для формы обратной связи
- GitHub Pages: сайт собирается в папку `docs/`

## Структура проекта

```
src/                    — исходники сайта
src/index.html          — главная
src/pages/              — разделы: вузы, страница вуза, из России, статьи, словарь, тесты, о проекте, заглушка
src/pages/articles/     — шаблон статьи и статья-пример про IELTS
src/pages/tests/        — подбор вуза и короткие тесты
src/stylesheets/        — шрифты, сброс, сетка, основные стили, адаптив
src/javascripts/        — точка входа, подключение стилей, общий скрипт app.js
src/javascripts/data/   — данные: 141 вуз, статьи, словарь, тесты, логотип
src/fonts/              — Rubik и Golos Text в woff2
src/public/images/      — фото вузов, фото команды, иконки сайта
docs/                   — собранный сайт для GitHub Pages
```

## Решения и сложности

- **Один набор данных на все страницы.** 141 вуз, статьи и словарь лежат в `src/javascripts/data/`, а страницы каталога, вуза, статьи и словаря собираются из них скриптом. Чтобы добавить вуз, не нужно трогать HTML.
- **Подбор вуза.** Каждый ответ теста имеет вес, вуз получает процент совпадения. Если для вуза нет цены или IELTS, ставим средний балл, чтобы он не выпадал из списка.
- **Висячие предлоги.** Русский текст в узких колонках часто оставлял «в», «и», «на» в конце строки. Скрипт при загрузке заменяет пробел после коротких слов на неразрывный.
- **Адаптив до 320px.** На самых узких телефонах длинные заголовки статей и звёзды на фото вылезали за экран. Для ширины до 400px отдельно уменьшили заголовки, отступы и звёзды.
- **Что сознательно не сделали.** Отказались от функций «Сохранённое» и «Сравнение»: ЗАГРАНЬ — медиа, а не сервис, и аккаунтов у пользователей нет.

Но результат почти всегда приходилось проверять глазами и просить переделать: текст вылезал из карточек, слова переносились посередине, мокапы ложились криво.
